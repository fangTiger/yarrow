# 全付费问卦与五行显式层设计

本轮沿用“夜の神社をターミナルで見る”的墨底、藏青、朱、金、白练和等宽链上凭证，不引入新的视觉语言。主操作收束为一个标价按钮；分类和用神覆盖放进次级展开项，默认路径无需确认分类。结果继续先展示五卦象群，原六步卡片压为一行状态摘要，交易凭证在同一行展开可查，把纵向空间让给排盘和五行。

收费不修改合约。不可判定问题采用 EIP-5792 原子批量授权和三笔 `DivinerVault.deposit`，稳态一次钱包确认把 0.05 USDC 按最小单位确定性分为 16,667、16,667、16,666，直接进入三库；不支持原子批量的钱包闭锁，不冒险顺序扣出部分费用。可判定问题保留现有登记合约和押注，三家全部应卦后由既有 treasury 自动预拨同额三库分账，最终结算回补。这样“是否押钱”仍由可判定性控制，但“是否付卦金”不再分轨。

五行区域以 SVG 表达两套关系：金色外环带箭头表示相生，朱色内星表示相克。旁边列出本卦上、下经卦五行和所属卦宫五行。六个爻位各用原生 `details` 就地解释纳甲地支、五行如何与宫五行比较而得到六亲、当前节气月下的旺衰，以及它和用户所选用神的关系。规则仍采用京房纳甲、八宫世应与《三命通会》五级旺衰表，单项旺衰不自动转译成吉凶。
