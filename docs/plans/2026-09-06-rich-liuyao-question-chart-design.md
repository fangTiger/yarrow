# 問轨五卦与京房纳甲排盘设计

问轨结果沿用现有“夜间神社终端”的墨底、藏青、朱、金、白练、明朝体、等宽链上数据与纵书点缀，不另起一套卡片语言。结果态标题下首先出现五卦象群：本卦占据视觉主位，其余互、综、变、错四卦环绕；点击任一卦，在群组底部切换“现状／症结／对方视角／结果／反面可能”的短说明。这样把产品主体放回首屏，同时保留状态、责任与零成本证据，但将其移到象群之后。移动端将象群压为主卦通栏、四卦双列，排盘外层单独横向滚动，页面本身继续禁止横向滚动。

规则只在服务端纯函数中计算。六爻先转为统一的自下而上阴阳位，再派生五卦；同一组位同时用于文王卦号与 UI，避免方向错位。装卦先由本卦号查八宫和世应，再按上下经卦装京房干支；本、变六亲均以本卦宫五行为我。伏神只补本卦未出现的六亲，并取本宫首卦相同爻位，不进一步判断飞伏旺衰。区块时间戳使用 UTC+8 民用日期和 00:00 日界，按儒略日—六十甲子公式得到日柱，再派生旬空和六神。所有流派选择、日界和未实现的月建旺衰/用神吉凶/应期在表下注明。

本轮扩展仍坚持“规则层产事实、前端层作说明”。中立分类器额外给出事项主题建议，但不读取卦象；确认卡用白名单选项让用户改选，服务端保留建议值、最终值和 `overridden`。排盘由最终主题取用神，并列出同六亲的用神爻、生用神的原神、克用神的忌神与生忌神的仇神。月建按节气月计算：太阳视黄经采用 NOAA/Meeus 近似式，十二地支区间采用 Y. T. Liu 的干支月 System 2；旺相休囚死五级表采用《三命通会·卷二》，而《增删卜易·四时旺相章》只用来交叉说明旺、相、余气与其余休囚，避免混称出处。

结果中的术语不再只是一张密表。五卦、卦宫/宫序、世应、六亲、六神、旬空、月建、旺衰、月破/日破/暗动、进退神和回头生克均使用原生 `details/summary` 就地展开；每段先解释术语，再引用当前卦的爻位和实际值。排盘前增加“这一卦怎么读”，固定按用神、旺衰、原忌仇神、世应、动变五步串联。卦辞沿用现有公共领域语料；彖辞和大象辞因语料缺失不拼接，并在 UI 直接说明。

测试按 RED-GREEN-REFACTOR 推进：先以乾、坤、屯、大有和姤/遁固定表，再实现规则；随后固定 甲子/壬申 日柱、旬空与六神；最后固定 API timestamp、五卦提示词和结果 DOM 顺序。构建后用 Playwright CLI 在固定 mock 区块上走完整問轨，桌面与移动分别断言象群底边不超过 viewport、文档宽度不超过 viewport，并把截图存入 `output/playwright/`。
