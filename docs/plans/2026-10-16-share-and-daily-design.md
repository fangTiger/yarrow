# 分享卡片与今日黄历 设计

> 日期：2026-10-16 · OpenSpec：`openspec/changes/share-and-daily/` · 计划：`docs/plans/2026-10-16-share-and-daily.md`

## 1. 背景

截至 2026-10-16，主网上的三笔付款都来自团队自测，还没有陌生用户。下一步是让更多人来，而且来了愿意再来：
- 用户能把结果发到社交平台，形成自然传播；
- 首页每天有免费的新内容，给人回访的理由。

## 2. 分享卡片

**形式**
- 1080×1350 竖版 PNG，深底金字，风格与站点一致。
- 卡头为品牌印加「三易」/「Yarrow」，卡尾为站点地址与一句可验证说明。

**三类卡片**

| 类型 | 内容 | 隐私 |
|---|---|---|
| 命理 | 「我的性格画像」：性格标签、一句总评、一生走势曲线（八步，只标年龄段）、一生走势概括 | 不含四柱、大运干支、年份、生辰 |
| 问事 | 所问、本卦 → 之卦（含卦画）、结论、三家判断（如「程颐 · 平 5 成」）、「六掷取自 Arc 区块哈希，可一键验证」 | 不含付款哈希 |
| 运势 | 所问、结论、十年走势曲线（标年份）、十年走势概括 | 不含四柱与生辰 |

**入口与交互**
- 总述完成后，总述面板下方出现「生成分享图」/「Share image」。
- 点开后预览图片，提供两个按钮：
  - 「分享」：浏览器支持带文件分享时调用系统分享；
  - 「下载」：保存 PNG。
- 只读示例也可生成（便于演示），卡尾注明「示例」。

**实现**
- `web/lib/share-card.ts`：纯函数，从公开视图构建卡片模型，并做文字分行（注入测量函数，便于测试）。
- 绘制在 canvas 上：正文用系统宋体与 Georgia，品牌与标题用已加载的毛笔子集字体。绘制前等待 `document.fonts.ready`。
- 英文卡片不含汉字，所问原文除外。

## 3. 今日黄历（首页）

**内容（来自现有 `GET /api/now`，不花模型费）**
- 公历与农历日期、日柱、当前节气；
- 建除与值神（黄道 / 黑道）；
- 宜、忌各最多 8 项；
- 冲煞；
- 喜神、财神、福神方位。

**入口**：卡片底部「看看你今天的运势 →」，跳转首页预填 `kind=fortune&horizon=today&q=我今天的运势如何？`（英文为「How will today go for me?」）。复用结果页体验那一期做的链接预填。

**英文**
- 新增 `web/lib/almanac-en.ts`：只用于展示，不进翻译术语表，不改 GLOSSARY_VERSION。内容包括建除十二值、值神十二、黄道 / 黑道、二十八宿、九星、八方位、十二生肖、二十四节气、农历月名，以及 lunar-javascript 全部宜忌词条。
- 查不到英文的词条不显示，英文页不得出现汉字。英文版不显示彭祖百忌与七十二候。

**位置**：首页一句话说明下方、类型卡之上；窄屏时折叠为一行摘要（日期 · 宜 3 项），点开看全部。

## 4. 发布文案（主管撰写）

面向外国用户的 X 长帖与 Reddit 帖草稿，存 `docs/launch/`。

## 5. 不做

- 不做二维码（需要新依赖）；
- 不做服务端渲染的卡片；
- 不做黄历订阅或推送。
