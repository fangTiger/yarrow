# 取消免费轨并显式呈现五行

## Why

問轨免费时，“没有人能为这一卦负责”容易退化为免责声明。产品需要让所有起卦都先支付卦金，再由收钱的易者当面承认其解读不产生责任；同时把已经参与排盘计算的五行关系公开给用户，而不是只显示计算后的六亲与旺衰标签。

## What Changes

- 取消用户可见的免费起卦和 mock/live 选择；mock 仅保留在开发、测试与排练命令中。
- 求卦按钮明示 0.05 USDC，并在未连接时自动唤起钱包、网络不符时自动请求切换、allowance 不足时自动续接授权。
- 分类器继续区分可判定与不可判定，但标准路径自动采用建议；用户可在提交前展开覆盖轨道和用神，不再多一次确认点击。
- 不可判定问题只收卦金、不让易者押钱；卦金以一次原子批量调用直入三座既有易者金库。
- 可判定问题沿用现有 commit 与易者押注；三家完成解读后由既有金库账户自动把卦金分入三座金库，不修改合约。
- 六步大进度轨压为细状态行，交易哈希与阶段详情收进可展开凭证区。
- 增加五行相生环、相克星、上下卦五行、卦宫五行与逐爻“纳甲 → 五行 → 六亲 → 月令旺衰 → 用神意义”说明。

## Impact

- Affected specs: `paid-oracle-flow`、`explicit-five-elements`、`compact-oracle-layout`
- Affected code: `web/app.tsx`、`web/styles.css`、`src/oracle/*`、`src/demo/*`、前端安全与内容测试
- Affected docs: README、双轨设计文档、实现计划
- Contracts: 不修改、不重新部署
