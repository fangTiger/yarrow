## ADDED Requirements

### Requirement: 白话总述

问事、命理与运势的每一卦，在三家断语都落笔（含删错留对后的断语）之后，系统 MUST 生成一份「白话总述」，用普通人能读懂的现代汉语把三家的结论合起来讲清楚。总述 MUST 包含：
- 一句话结论（不超过 40 字），直接回答所问；
- 三家一致之处；
- 三家分歧之处（三家一致时可省略）；
- 二至四段白话解释，说明为什么这样判断；
- 解法（心法、怎么做、别做什么，见「解法」要求）；
- 需要留意的时间及其成立条件（有则写）。

命理不给吉凶评级；运势另加一句十年走势概括。

#### Scenario: 问事出总述

- **WHEN** 用户问「这次面试能过吗」，三家分别断为平五成、凶四成、平五成
- **THEN** 结果页最上方显示白话总述：一句话结论（如「把握不大，偏向不顺，但未成定局」）、三家同异、原因与留意时间，随后是解法

#### Scenario: 命理出总述

- **WHEN** 用户问「我适合做什么」
- **THEN** 总述用白话概括三家所取用神的不同含义，并在解法中给出长处怎么用，不出现吉凶评级

### Requirement: 总述的内容边界

总述 MUST 只依据三家断语与本卦盘面事实，MUST 不引入三家都没有说过的结论，也 MUST 不出现盘面中不存在的干支、卦名、十神或关系。术语首次出现时 MUST 用括号附上白话解释，例如「用神（代表所问之事的那一爻）」。总述的吉凶倾向 MUST 与合议一致：合议六成以上偏向顺，四成以下偏向不顺，其余为中性。总述 MUST 不给出医疗、法律或投资结论，涉及健康时 MUST 建议就医，并遵守与三家相同的文化用语约束。

#### Scenario: 总述编造盘面

- **WHEN** 总述写了盘面中不存在的「寅木官鬼」
- **THEN** 核对失败并带错误说明重写；仍不符则按删错留对删去该句

#### Scenario: 总述与合议相反

- **WHEN** 合议为三成，而总述的结论写「大有可为」
- **THEN** 判为不一致并重写

### Requirement: 总述的核对与兜底

总述 MUST 经过与三家相同的盘面核对，不符时带具体错误说明重写，最多两次；仍有不符时 MUST 删错留对后展示。总述的模型调用失败时，系统 MUST 在后台自动再试一次；仍失败时，总述位置 MUST 显示「白话总述暂未生成」与免费重试入口，三家断语照常可看。只有一或两家落笔时，总述 MUST 照常生成，并注明「依据 N 家断语」。

#### Scenario: 一家未落笔

- **WHEN** 京房两次调用都失败，程颐、邵雍已落笔
- **THEN** 总述依据程颐、邵雍生成，并注明「依据两家断语」

### Requirement: 结果页布局与重算

结果页 MUST 把白话总述放在最上方（时空栏与问题之后、三家断语之前），解法紧随总述之后。三家断语 MUST 默认折叠为「看三家依据」，展开后照旧显示用神对照、合议线与三张断语卡片。三家落笔期间，总述位置 MUST 显示进度，如「三家落笔中（2/3）」「正在写白话总述」。改事项、换日口径切换、单家重试完成后，系统 MUST 重新生成总述，且不收费。总述 MUST 随解读存档，分享链接可见。

#### Scenario: 改事项后重写总述

- **WHEN** 用户把事项从「求职」改为「考试」，京房重新落笔
- **THEN** 白话总述随之重新生成，不产生新的付款

### Requirement: 解法

白话总述 MUST 同时给出「解法」，回答「那我该怎么办」，问事、命理与运势都有。解法 MUST 包含：
- 心法：问事为本卦《大象传》原文加一句白话；命理与运势为「三家取用」（三家各自所取用神与调候取用）加一句白话处事原则。原文与三家取用 MUST 由系统给出，不由模型生成；
- 怎么做：二至三步，每步写明做什么、依据盘面哪一点，可附时机；
- 别做什么：一至二条。

总述 MUST 不再单独输出「建议」；没有解法的旧存档 MUST 照旧显示其建议。

#### Scenario: 问事的解法

- **WHEN** 用户问「这次面试能过吗」，本卦为兑为泽
- **THEN** 解法心法显示「丽泽，兑；君子以朋友讲习。」及一句白话
- **AND** 怎么做的每一步都写明依据的盘面要点

#### Scenario: 运势的解法

- **WHEN** 用户问「我今年运势如何」
- **THEN** 解法心法显示三家各自所取用神与调候取用，并给出今年怎么过的两到三步

### Requirement: 解法的边界

解法 MUST 经过与总述相同的盘面核对，心法原文在核对前剔除。解法 MUST 不给颜色、方位、数字、佩戴之类的趋避，MUST 不推荐开光物、法器、符咒、护身符、吉祥物或摆件，MUST 不涉及放生、捐款、供奉；出现这类内容时 MUST 带错误说明重写，仍不符则删去。解法 MUST 不给医疗、法律、投资结论，不渲染恐惧，不打包票。

#### Scenario: 解法推荐法器

- **WHEN** 模型在怎么做里写「佩戴开光貔貅可化解」
- **THEN** 核对失败并带错误说明重写；仍不符则删去该步
