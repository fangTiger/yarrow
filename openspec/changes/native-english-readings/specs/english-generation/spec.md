## ADDED Requirements

### Requirement: 英文直接生成

下单语言为英文（`lang: "en"`）时，问事三家与总述、命理与运势三家与总述（含性格画像、一生走势、逐运与逐年断语）、起名三个流派与合参 MUST 直接用英文写成，MUST NOT 先写中文再翻译。下单语言缺省或为中文时，生成、核对与显示 MUST 与原来一致。存档与公开 reading MUST 记录 `lang`。

#### Scenario: 英文下单

- **WHEN** 用户在英文界面付款下一卦命理
- **THEN** 三家与总述写完即为英文，结果页无需翻译、无额外等待

#### Scenario: 中文下单不受影响

- **WHEN** 用户在中文界面下单，问题用英文写
- **THEN** 仍用中文作答，核对规则不变

### Requirement: 英文输出的核对

英文解读 MUST 保持与中文同等的防编造强度。`evidence[].claim` MUST 用中文书写，并沿用中文的逐条事实核对。展示给用户的英文字段 MUST 通过以下核对：

- 不含汉字（起名候选字与姓氏等白名单除外）；
- 出现的六十甲子拼音对、十神英文名、问事的「地支 + 五行 + 六亲」组合 MUST 为本盘实有；缺时柱时不得出现时柱干支，并须写明判断限制；
- 不得出现民俗趋避与押注赔付类英文禁用词；
- 吉凶与把握、画像条数、倾向与合议等结构规则与中文一致；
- 长度不超过英文上限。

不过时 MUST 带错误说明重写，三次仍不过则按英文句子删错留对；修复后仍不合格则判为失败，可免费重试。

#### Scenario: 英文正文编造干支

- **WHEN** 某家英文正文写出本盘不存在的「Jia Zi」
- **THEN** 核对失败并重写

#### Scenario: 英文正文混入汉字

- **WHEN** 某家英文 headline 含汉字
- **THEN** 核对失败并重写

### Requirement: 英文解读的显示

英文界面打开英文解读时 MUST 直接显示，不请求翻译、不显示翻译状态。中文界面打开英文解读时 MUST 照常显示，并提示「本卦以英文生成」，提供一键切换到英文界面。

#### Scenario: 中文界面打开英文解读

- **WHEN** 中文用户打开一个英文下单的分享链接
- **THEN** 页面显示英文正文与「本卦以英文生成」提示，可一键切到英文界面
