## MODIFIED Requirements

### Requirement: 按单元翻译

英文模式下的结果页 MUST 显示英文解读。英文下单的解读直接用英文生成，MUST NOT 翻译（见 english-generation）。中文生成的解读在英文模式下查看时，MUST 先完成中文生成与核对，再按单元翻译为英文：总述为一个单元，每家（起名为每个流派）各为一个单元。单元 MUST 在到达终态后才翻译，翻译 MUST 免费且幂等，译文 MUST 缓存，并以「原文 + 提示词版本 + 术语表版本」的哈希判断是否失效。

旧存档中标记了 `translateTo: "en"` 的解读 MUST 仍在每个单元到达终态时由服务端立即在后台翻译该单元。中文下单、之后切到英文查看的解读，MUST 在整卦完成后由页面触发翻译。翻译失败 MUST 不影响中文解读的状态。

英文模式下，中文已写完而译文未到的单元 MUST 显示为占位（正在落笔或翻译中），MUST 不显示中文正文；译文失败的单元 MUST 显示英文提示与免费重试，MUST 不回退显示中文。

#### Scenario: 英文下单不翻译

- **WHEN** 用户在英文界面付款
- **THEN** 解读直接以英文生成，不建立翻译单元

#### Scenario: 英文页等待中不露中文

- **WHEN** 英文模式下某家中文已写完、译文未到
- **THEN** 该家显示翻译中的占位，页面解读区域不出现汉字

#### Scenario: 打开英文结果页

- **WHEN** 英文模式下打开一卦中文下单、已完成的结果页
- **THEN** 页面先显示「Translating…」，随后各单元陆续显示英文

#### Scenario: 重试后译文失效

- **WHEN** 某家免费重试后中文内容改变
- **THEN** 该家旧译文失效，重新翻译
