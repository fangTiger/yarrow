## Context

六爻数组自下而上编号 1–6，现有 `KING_WEN` 表已按同一位序把阴阳位映射到文王卦序。新能力必须复用这一位序，避免五卦、纳甲与 UI 绘制各自维护不同编码。

## Goals / Non-Goals

目标：同源确定性推算五卦；正确生成京房纳甲基础盘；以可否决的事项主题确定用神；补齐月令旺衰、日月冲破和动变关系；让每个术语都能就地说明其定义与本卦含义；让卦象进入结果首屏；给模型与 mock 相同的五卦与用神上下文；移动端仅排盘表自身横向滚动。

非目标：不做综合吉凶裁决、应期、飞伏强弱或神煞断语；不把装卦事实包装成预测结论；不改合约、回放、消融或秘密配置；不补写当前语料缺失的彖辞和大象辞。

## Considered Approaches

1. 前端临时推算全部排盘：响应变小，但服务端解读拿不到五卦，且规则会散落，拒绝。
2. 引入第三方历法/排盘运行时依赖：覆盖广，但增加供应链与流派隐式默认值，拒绝。
3. 新增纯函数规则模块，由服务端一次生成结构化五卦与排盘，前端只负责展示：可测试、可复算、无额外随机源，采用。

## Decisions

1. 五卦统一从本卦阴阳位推算：互卦自下而上为本卦第 2、3、4、3、4、5 爻；变卦只翻转 6/9；错卦翻转全部六爻；综卦反转爻序。
2. 八宫使用固定的本宫、一世、二世、三世、四世、五世、游魂、归魂表；世位依次为 6、1、2、3、4、5、4、3，应位与世位相隔三爻。
3. 纳甲采用京房纳甲固定八经卦内外卦干支表。变卦纳甲按变后上下卦重排，但本、变两列六亲均以本卦所属宫五行为“我”。
4. 伏神采用《增删卜易》口径：本卦缺失的六亲回本宫首卦寻找，并伏于对应爻位；只展示排盘事实，不推断飞伏吉凶。
5. 日柱采用区块 Unix 秒转 UTC+8 公历日期、民用 00:00 换日；以已知甲子日与儒略日公式作测试锚点。UI 明示该口径，并说明未采用子初换日。
6. 旬空采用六甲旬空；六神按日干起首并从初爻依青龙、朱雀、勾陈、螣蛇、白虎、玄武顺排。
7. 页面结构在结果态调整为标题 → 五卦象群 → 本轮所问 → 状态/责任/零成本 → 排盘/解读。象群按钮切换角色说明，本卦占双格，其余四卦环绕。
8. 事项分类与既有轨道分类同在 `question-classifier` 边界内，但保持两个独立结论。关键词只给出主题建议，不读取卦象；UI 用白名单下拉框允许改选，服务端重新校验主题键并记录 `suggestedKey`、`key` 与 `overridden`。
9. 月建采用节气月：子月从大雪至小寒、丑月至立春，依次类推。节气边界用 NOAA/Meeus 太阳视黄经公式近似计算，运行范围限定为 1901–2099；若落在交节临界范围，UI 明示需以权威天文历书复核。
10. 旺相休囚死采用《三命通会·卷二》“盛德乘时曰旺”所列五级生克表；《增删卜易·四时旺相章》只作为六爻语境下旺、相、土月余气与其余休囚的交叉说明，不把后者伪称为五级表。
11. 月破取月建相冲；静爻受日辰冲时，旺相为暗动，其余为日破。进退神采用《增删卜易》所列固定地支对；回头生克只比较动爻与同位变爻五行。
12. 术语说明使用原生 `details/summary`，键盘和点击均可展开。排盘层输出可复算事实，UI 以当前卦宫、爻位、用神爻、旺衰和动变值组成情境说明；另设固定次序的“这一卦怎么读”。

## Error Handling

- 六爻不是恰好六个 6/7/8/9 时拒绝生成。
- 区块时间戳不是非负整数时拒绝换算，不回退到浏览器当前时间。
- 卦号不在八宫表时抛出明确错误，不猜测卦宫或世应。
- 仅实现有明确来源与测试闭环的排盘字段；不做完整吉凶综合与应期，并在 UI 标注。
- 时间超出 1901–2099 时拒绝近似节气月计算；交节临界时不把近似结果包装成精确历书结论。
- 主题关键词没有命中时给出“人际/同辈”的可见建议与低置信理由，并要求用户可改选，不静默猜测。

## Testing

- 单元测试逐项覆盖互、变、错、综位序。
- 表驱动已知卦例覆盖乾为天、坤为地、水雷屯、火天大有的卦宫、世应、纳甲与六亲，并以姤/遁验证伏神。
- 日柱测试覆盖 2000-01-07 甲子与 2024-09-05 壬申，断言旬空与六神。
- 解读提示词测试断言五卦全部进入同一次模型输入；确定性 mock 不访问网络。
- 内容测试固定五卦交互、排盘表头、流派说明与 DOM 顺序；浏览器验收以桌面和移动视口截图确认象群位于首屏，并读取页面宽度确认无整页横向溢出。
- 已知问题测试固定“我该不该辞职”→工作/官职→官鬼，并验证用户可改选且原问题不改写。
- 已知日期测试固定 2024-09-05 为申月；表驱动覆盖金月五行旺相休囚死、月破、壬申日暗动/日破。
- 已知卦例覆盖进退神、回头生克、六冲六合和风泽中孚艮宫游魂世四应初；内容测试逐项固定术语展开与阅读引导顺序。
