## Context

完整设计见 `docs/plans/2026-10-13-yarrow-global-design.md`。主管与评审 agent 两轮讨论后定稿，用户授权分批交 codex 实现。

## Decisions

- 出生时区：Asia/Shanghai 沿用现有逻辑与夏令时表，不用 tzdb，以免 1940–49 年夏令时与地方平时改动夹具；其他时区按 A/B 拆分：
  - A：instant 换算的北京钟面时间，决定年月、胎元、大运、起运；
  - B：当地标准时，决定日时；
  - 年月不一致时，按 A 重算十神、命宫、身宫。
- 翻译：中文生成并核对后，按单元翻译；译文核对器确定性检查；旁路存储；只在单元到终态后才翻译。
- 英文模式下类型与事项由用户手选，关键词只做预选。
- 古文用离线译表，不用 Legge；起名的用字分析用英文模板。

## Risks / Trade-offs

- 翻译质量依赖模型：靠术语表、离线译表与核对器约束一致性。
- 海外出生的边界情况（夏令时重复或跳跃时段、离交节半天以内）：标注并用夹具覆盖。
