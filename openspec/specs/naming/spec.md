## Requirements
### Requirement: 起名入口

首页 MUST 提供「起名」类型，下设「人名」与「商号」。规则分类 MUST 把含起名、取名、名字的问题识别为起名并标记为可用；同时含公司、店、品牌、商号、字号、工作室、餐厅、咖啡、茶馆、门店、企业之一的，MUST 识别为商号，否则为人名。起名 MUST 与其它类型一样，只收一次 0.05 USDC 卦金。

#### Scenario: 给孩子起名

- **WHEN** 用户输入「给孩子起个名字」
- **THEN** 首页自动选中「起名 · 人名」，问卦按钮在姓氏与生辰有效后可用

#### Scenario: 给咖啡馆起名

- **WHEN** 用户输入「给我的咖啡馆起个名字」
- **THEN** 首页自动选中「起名 · 商号」

### Requirement: 人名与商号的输入

人名 MUST 收姓氏（1–2 个汉字，须在《通用规范汉字表》内）、单名或双名、生辰，期望为选填。生辰 MUST 支持「还没出生（按预产期）」，此时性别 MUST 可选「不限」。商号 MUST 收行业与期望（至少 2 字）、字号字数（2–4），店主生辰为选填。起名用的生辰 MUST 不覆盖本人生辰档案。

#### Scenario: 按预产期起名

- **WHEN** 用户勾选「还没出生」，填写预产期并选择性别「不限」
- **THEN** 系统按预产期排三柱，起中性名字，结果页标题注明「按预产期」，起名依据注明时辰不详

#### Scenario: 姓氏不在字表内

- **WHEN** 用户填写的姓氏不在《通用规范汉字表》8105 字内
- **THEN** 就地提示且问卦按钮不可用

### Requirement: 起名三家

系统 MUST 由三家各给 3 个名字：五行补益（每个名字至少一个字属喜用五行）、诗文出处（名字各字出自程序给出的候选诗句之一）、音形字义（人名的姓加名声调不得全同）。补益五行 MUST 由程序确定：有生辰时，先补八字（天干与地支本气）中缺的五行，同在调候喜用中的优先；只缺一行时再加一个调候喜用五行；不缺时按调候取用天干换算，取前两个；商号未填店主生辰时按行业关键词查表，查不到由五行家自选并写明。名字的每个字 MUST 是《通用规范汉字表》内、且不在不宜入名词表中的字。系统 MUST 不使用五格、三才、数理之说。

#### Scenario: 五行家不合喜用

- **WHEN** 喜用为火、水，五行家给出的名字两个字都属木
- **THEN** 核对失败并带错误说明重写；三次调用后仍不合的名字删去

#### Scenario: 诗文家编造出处

- **WHEN** 诗文家给出的名字含有所引候选诗句中没有的字
- **THEN** 核对失败；出处一律由程序按候选编号回填书名、题名与原句

### Requirement: 字库与逐字信息

每个名字 MUST 附逐字信息：拼音与声调、五行及判定依据、康熙笔画、简短释义；三级字 MUST 标「较生僻」。诗文出处原句 MUST 按名字中字的出现次数依次加重，不能加重同字的所有位置。字的五行 MUST 按康熙部首优先、声母五音其次判定，页面 MUST 说明这一规则。字库来源与许可 MUST 记录在案。

#### Scenario: 查看名字卡

- **WHEN** 名字含「泽」
- **THEN** 名字卡显示 zé、五行水（部首·水）、康熙 17 画与释义

### Requirement: 三家合参

三家结束后，系统 MUST 生成三家合参，推荐 2–3 个名字并给理由，概括三家思路的异同，并给出怎么挑的提示（念出来听、方言谐音、人名查重名或商号查商标）。合参输入 MUST 逐名附音律提示，并优先推荐没有音律提示的名字。推荐的名字 MUST 是本卦已通过核对的名字。人名提示 MUST 不提商标、工商；商号提示 MUST 不提重名、户口。合参调用失败时 MUST 自动再试一次，仍失败给免费重试，九个名字照常可看。

#### Scenario: 合参推荐了不存在的名字

- **WHEN** 合参推荐的名字不在本卦合格名字中
- **THEN** 该推荐被删去；全部被删时取各家首个合格名字

#### Scenario: 有足够的无全同声调候选

- **WHEN** 合参推荐带「姓名声调全同」提示的名字，且另有至少两个不带该提示的合格名字
- **THEN** 核对失败并要求重写；最终修补时从各家首个不带该提示的合格名字补齐

### Requirement: 起名的隐私与边界

起名存档 MUST 不含原始出生日期与时间，只存四柱与喜用。页面 MUST 提示人名上户口前查重名、商号注册前查询商标与工商登记。名字说明 MUST 不含开光、法器、符咒、转运、化煞、放生、供奉等用语，也不承诺改运。

#### Scenario: 读取起名存档

- **WHEN** 读取一份人名起名存档
- **THEN** 存档含姓氏、四柱与喜用，不含原始出生日期与时间

### Requirement: 五行分析

人名与填了店主生辰的商号，结果页 MUST 在三家合参之前显示「五行分析」：八字五行计数（天干与地支本气）、缺的五行、补益五行及一句结论（如「八字缺金，宜补金；调候喜木，兼补木」），以及补益五行的寓意；并 MUST 画出五行生克图（相生成圈、相克成星，标出缺、补与日主，图下写所补五行的生克关系）。页面 MUST 说明「缺什么补什么」是民间通行的起名思路，并说明本站同时参考调候喜用。未填店主生辰的商号 MUST 显示按行业确定的五行。

#### Scenario: 八字缺金

- **WHEN** 八字天干与地支本气中没有金
- **THEN** 五行分析标出「缺」金，结论写宜补金
- **AND** 五行补益家每个名字至少一个字属金或另一个补益五行

### Requirement: 名字卡的参考评分与分析

每个名字 MUST 显示逐字字块（康熙笔画、五行、拼音）、补益标记、参考评分（好听、字形、八字五行、诗文意蕴四项及综合）、用字分析、字义分析、意蕴内涵（语料中含该字的诗句）与性格标签。评分、用字分析与意蕴内涵 MUST 由程序按公开的规则生成，页面 MUST 注明「参考分，仅供参考」与计分规则。评分 MUST 不使用五格、生肖、星座。

#### Scenario: 查看名字卡评分

- **WHEN** 名字「书瑶」中「瑶」属所缺的金
- **THEN** 名字卡标「补金」，八字五行分含所缺五行加分
- **AND** 用字分析写明「瑶」五行属金，补八字所缺之金

#### Scenario: 查看五行生克图

- **WHEN** 八字缺金、补金与水
- **THEN** 生克图中金为虚线描边并标「缺」「补」，水标「补」
- **AND** 图下写「补金：土生金，金生水；金克木，火克金」
