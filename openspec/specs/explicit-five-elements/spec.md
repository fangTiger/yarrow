# explicit-five-elements Specification

## Purpose
规定六爻排盘中五行相生相克、卦宫与逐爻纳甲五行的显式呈现，以及五行、旺衰与用神关系的说明方式。本能力服务于三易问事结果页的排盘详情区，确保用户能看到六亲、旺衰由何而来，而不是只看到结论标签。

## Requirements
### Requirement: 五行关系与本卦实值

系统 MUST 显示相生环、相克星、本卦上下卦五行、卦宫五行及每爻纳甲五行。相生固定为木生火、火生土、土生金、金生水、水生木；相克固定为木克土、土克水、水克火、火克金、金克木。

#### Scenario: 逐爻解释六亲来源

- **WHEN** 卦宫五行为土且某爻纳甲五行为木
- **THEN** 界面说明木克土是“克我”
- **AND** 说明该爻因此为官鬼，而不是只显示官鬼标签

### Requirement: 五行与旺衰用神打通

每爻说明 MUST 同时给出当前节气月下的旺相休囚死，并说明它是用神自身、原神、忌神、仇神或一般爻；不得把单一旺衰标签直接写成吉凶结论。

#### Scenario: 同时说明旺衰与用神关系

- **WHEN** 用户展开逐爻五行推导
- **THEN** 每爻同时显示当前节气月下的旺衰与用神关系
- **AND** 不把单一旺衰标签直接写成吉凶结论
