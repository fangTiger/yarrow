# unified-question-entry Specification

## Purpose
规定首页以单一输入接收用户问题，并通过规则分类或手动选择分流到问事、命理、运势与起名。本能力统一三易各术数的入口、类型提示和生辰补填，避免分类不明确时擅自发起付费流程。
## Requirements
### Requirement: 单一问题入口

首页中间 MUST 只保留问题类型选项（问事、运势、命理）、随类型变化的一行细项（问事的事项，或运势的时间范围）、问题输入框、命理与运势所需的生辰输入，以及「问卦 · 0.05 USDC」按钮。最近记录 MUST 收在右上角的「卦历」小图标里，点开后以浮层列出。首页 MUST 不显示时空栏与最近记录面板，也 MUST 不出现押注、赔付、轨道选择、演示模式或统计指标。

#### Scenario: 首次打开首页

- **WHEN** 用户打开首页
- **THEN** 页面中间依次是「想问什么？」、问事 / 运势 / 命理三个选项、问题框与「问卦 · 0.05 USDC」按钮
- **AND** 右上角有「卦历」小图标与钱包入口
- **AND** 不出现时空栏、右侧最近记录面板，以及问轨、赌轨、mock、live、Brier 等字样

#### Scenario: 查看卦历

- **WHEN** 用户点击右上角「卦历」图标
- **THEN** 浮层列出本机最近记录，点击任一条打开该卦结果页

### Requirement: 规则问题分类

系统 MUST 用确定性规则把问题分类为问事、命理、运势、起名、择日、星座、合婚或其它，并对运势提取时间范围（今天、本月、今年、明年或指定年份，默认今年），对问事给出事项与用神建议。分类 MUST 不调用模型、不读取卦象或命盘、不下断语；无法确定时 MUST 归为问事。

#### Scenario: 运势问题

- **WHEN** 用户输入「我本月财运怎么样」
- **THEN** 分类为运势，时间范围为本月，且需要生辰

#### Scenario: 命理问题

- **WHEN** 用户输入「我适合做什么工作」
- **THEN** 分类为命理，且需要生辰

#### Scenario: 无法确定

- **WHEN** 用户输入「那件事会怎样」
- **THEN** 分类为问事，事项默认按现有规则给出

### Requirement: 类型选项与自动识别

命理、问事、运势、起名四个选项 MUST 始终可见并按此顺序排列，默认选中命理。命理的问题 MUST 选填：问题为空时按默认问题「我这一生的运势走向与性格如何？」（英文「How will my life unfold, and what is my character like?」）处理，且不要求手选类型、不等待分类。用户输入问题后，系统 MUST 按规则分类自动切换到识别出的类型与细项（事项或时间范围），并以小字提示「已自动识别为运势 · 今年」之类；用户手动点选的类型 MUST 优先，之后的输入不再自动改动。用户 MUST 能在付款前改为其它类型、事项或时间范围，修改 MUST 不产生费用。

#### Scenario: 只填生辰

- **WHEN** 用户打开首页，不写问题，只填生辰
- **THEN** 类型为命理，可直接付款，结果按默认问题生成

#### Scenario: 改为问事

- **WHEN** 分类为运势而用户把标签改为问事
- **THEN** 不再要求生辰，付款后自动六掷起卦

### Requirement: 未开放类型引导

对第一期未开放的类型（起名、择日、星座、合婚、其它），系统 MUST 显示「即将开放」及改为问事的具体建议，并 MUST 不发起付款。

#### Scenario: 起名问题

- **WHEN** 用户输入「给女儿起个名字，姓王」
- **THEN** 页面提示起名即将开放
- **AND** 建议可改为问事，例如「给孩子起名叫某某好不好」
- **AND** 不唤起钱包

### Requirement: 内嵌生辰输入

选中命理或运势时，问题框下方 MUST 直接内嵌一行生辰输入（见 `birth-profile`），不弹出独立表单；本机已有本人生辰时 MUST 预先填好。生辰无效或未填时，问卦按钮 MUST 不可用并就地说明原因。选回问事时生辰输入 MUST 收起。

#### Scenario: 没有生辰问运势

- **WHEN** 本机没有生辰档案而用户问「我今年运势如何」
- **THEN** 选项自动切到运势，问题框下方出现生辰输入
- **AND** 填好出生日期与时辰、选好性别后才能问卦

#### Scenario: 改回问事

- **WHEN** 用户在运势下点选「问事」
- **THEN** 生辰输入收起，可以直接问卦
