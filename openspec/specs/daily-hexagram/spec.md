# daily-hexagram Specification

## Purpose
规定首页「今日一卦」：每天用北京零点后首个 Arc 区块抽一卦，人人相同、可复算、免费且不调用模型。本能力给没有钱包的访客一个每天回来的理由，并演示链上随机可核验。
## Requirements
### Requirement: 每日一卦

系统 MUST 每天提供一卦「今日一卦」，所有访客看到同一卦，免费且不调用模型。抽卦规则如下：
- 当日按北京时间（UTC+8）计；
- 取 Arc 主网上时间戳不早于当日零点的第一个区块；
- 第 i 掷（i = 1…6）取 `keccak256(encodePacked(string "sanyi-daily-v1", bytes32 blockHash, string date, uint8 i))` 的最低三位作为三枚铜钱（1 为背），换算为爻值 6–9；
- date 形如 `2026-10-18`。

结果 MUST 按日缓存，同一天重复请求 MUST 返回同一卦。首页 MUST 展示：卦象、本卦与之卦名、动爻、卦辞与动爻爻辞（英文界面用英译，中文界面用原文）、区块号与区块哈希（附浏览器链接）。首页还 MUST 提供「就这件事问一卦」的入口，带入问事并付费。

#### Scenario: 同一天同一卦

- **WHEN** 两位访客在同一个北京日期打开首页
- **THEN** 看到同一卦、同一区块出处

#### Scenario: 可复算

- **WHEN** 有人取当日首个区块哈希按公式计算
- **THEN** 得到与页面一致的六爻

#### Scenario: 不花钱

- **WHEN** 访客查看今日一卦
- **THEN** 不需要钱包，服务端不调用任何模型
