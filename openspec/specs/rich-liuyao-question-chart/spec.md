# rich-liuyao-question-chart Specification

## Purpose
规定六爻问事的确定性排盘：五卦、京房纳甲、八宫世应、日柱月建、旺衰动变、用神事项及术语说明。所有排盘事实均由程序生成、可按同一区块时间复算，模型只能在这些事实之上解读，不得自行生成排盘字段。
## Requirements
### Requirement: 同源五卦

系统 MUST 从同一组六爻确定性生成本卦、互卦、变卦、错卦与综卦，不得增加随机源或模型调用。

#### Scenario: 推算五卦

- **WHEN** 六爻自下而上给定为 6/7/8/9
- **THEN** 互卦使用第 2、3、4、3、4、5 爻，变卦只翻转 6/9，错卦翻转全部阴阳，综卦反转爻序

### Requirement: 京房纳甲排盘

系统 MUST 按京房纳甲、八宫世应与本卦宫五行生成卦宫、纳甲、六亲、六神、世应、旬空与伏神，不得由模型生成这些字段。

#### Scenario: 已知卦例校验

- **WHEN** 输入乾为天、坤为地、水雷屯或火天大有
- **THEN** 卦宫、世应、逐爻纳甲与六亲符合固定对照表

#### Scenario: 六亲不上卦

- **WHEN** 本卦可见六亲缺项
- **THEN** 系统从本宫首卦对应爻位展示伏神，不生成飞伏吉凶断语

### Requirement: 区块时间日柱

系统 MUST 只使用第一掷所用 Arc 区块的时间戳换算日干支、旬空、六神、月建，并回传该区块号、时间戳、日柱和日界口径供复算；同一卦的奇门时盘与黄历 MUST 使用同一时间戳。

#### Scenario: 同一区块复算

- **WHEN** 使用相同的第一掷区块时间戳重新排盘
- **THEN** 日干支、旬空、六神顺序与月建完全相同

#### Scenario: 六掷跨越多个区块

- **WHEN** 第一掷与第六掷使用不同区块
- **THEN** 日辰、月建、奇门与黄历均按第一掷区块时间计算

### Requirement: 首屏五卦象群

问事结果 MUST 在首屏展示本卦卦画、卦名、动爻、之卦以及本、互、变、错、综五卦缩略；排盘宽表 MUST 自身横向滚动且不得令页面横向滚动。

#### Scenario: 桌面与移动查看结果

- **WHEN** 问事在桌面或 390 像素宽移动视口完成
- **THEN** 本卦卦画、卦名与五卦缩略位于首屏
- **AND** 页面横向无溢出

### Requirement: 解释边界

排盘事实（五卦、纳甲、六亲、六神、世应、旬空、伏神、旺衰、空破、动变）MUST 由程序生成，不得由模型生成；排盘引擎本身 MUST 不计算综合吉凶与应期。三家解读 MAY 给出吉凶等级与带条件的应期，但 MUST 通过 `question-three-schools` 规定的盘面证据核对。UI MUST 标注京房纳甲、八宫世应、六甲旬空、节气月、旺衰来源与 UTC+8 口径。

#### Scenario: 查看规则说明

- **WHEN** 用户查看问事排盘
- **THEN** 用户能看到所依流派、换日口径与来源说明

#### Scenario: 解读引用盘面

- **WHEN** 京房的断语提到"寅木官鬼旬空"
- **THEN** 该陈述只有在排盘中二爻确为寅木官鬼且日旬空含寅时才会展示

### Requirement: 可否决的用神主题

系统 MUST 根据原问题给出可见的事项主题与用神建议，MUST 允许用户在起卦前改选主题，并 MUST 在结果中同时保留建议主题、最终主题与是否改选。事项分类不得读取卦象或调用解读模型。

#### Scenario: 辞职问题取官鬼

- **WHEN** 用户输入“我该不该辞职”
- **THEN** 分类建议显示“工作／官职”且用神为“官鬼”
- **AND** 用户可以改选其他主题，原问题保持不变

### Requirement: 节气月与逐爻旺衰

系统 MUST 从同一起卦区块时间戳按 UTC+8 与节气月口径生成月建，并依所选公开来源为每爻生成旺相休囚死、月破、日破与暗动。交节临界或算法有效范围外 MUST 显示不确定性或拒绝计算，不得伪装精确。

#### Scenario: 申月逐爻强弱

- **WHEN** 起卦时间为 2024-09-05 且未到白露
- **THEN** 月建为申、月令五行为金
- **AND** 金为旺、水为相、土为休、火为囚、木为死

### Requirement: 动变与卦性事实

系统 MUST 对动爻生成进神、退神、回头生、回头克事实，并标注本卦与变卦是否为六冲或六合；每爻 MUST 带用户指定的爻位象征，但不得据此自动生成吉凶结论。

#### Scenario: 已知动变关系

- **WHEN** 动爻地支按固定对照发生寅化卯或卯化寅
- **THEN** 分别标注进神或退神
- **AND** 同位变爻生克动爻时分别标注回头生或回头克

### Requirement: 情境化术语说明与阅读引导

UI 中出现的五卦、卦宫、宫序、世应、六神、六亲、伏神、旬空、月建、旺衰、冲破与动变术语 MUST 可在原处点击展开，并同时说明定义和本卦实际值。系统 MUST 按用神→旺衰→原神忌神仇神→世应→动变生成一段人话阅读引导。

#### Scenario: 风泽中孚说明

- **WHEN** 本卦为风泽中孚
- **THEN** 用户可展开看到“艮宫・游魂”和“世四应初”的定义
- **AND** 说明结合四爻和初爻的位置象征，不只给出词典定义
