# reading-translation Specification

## Purpose
规定中文解读按总述和各家拆分为可缓存、可失效、可核对的英文翻译单元，并统一术语与《周易》古文译法。本能力支撑 Yarrow 英文结果页，同时限制并发、失败冷却和每日翻译用量。
## Requirements
### Requirement: 按单元翻译

英文模式下的结果页 MUST 显示英文解读。英文下单的解读直接用英文生成，MUST NOT 翻译（见 english-generation）。中文生成的解读在英文模式下查看时，MUST 先完成中文生成与核对，再按单元翻译为英文：总述为一个单元，每家（起名为每个流派）各为一个单元。单元 MUST 在到达终态后才翻译，翻译 MUST 免费且幂等，译文 MUST 缓存，并以「原文 + 提示词版本 + 术语表版本」的哈希判断是否失效。

旧存档中标记了 `translateTo: "en"` 的解读 MUST 仍在每个单元到达终态时由服务端立即在后台翻译该单元。中文下单、之后切到英文查看的解读，MUST 在整卦完成后由页面触发翻译。翻译失败 MUST 不影响中文解读的状态。

英文模式下，中文已写完而译文未到的单元 MUST 显示为占位（正在落笔或翻译中），MUST 不显示中文正文；译文失败的单元 MUST 显示英文提示与免费重试，MUST 不回退显示中文。

#### Scenario: 英文下单不翻译

- **WHEN** 用户在英文界面付款
- **THEN** 解读直接以英文生成，不建立翻译单元

#### Scenario: 英文页等待中不露中文

- **WHEN** 英文模式下某家中文已写完、译文未到
- **THEN** 该家显示翻译中的占位，页面解读区域不出现汉字

#### Scenario: 打开英文结果页

- **WHEN** 英文模式下打开一卦中文下单、已完成的结果页
- **THEN** 页面先显示「Translating…」，随后各单元陆续显示英文

#### Scenario: 重试后译文失效

- **WHEN** 某家免费重试后中文内容改变
- **THEN** 该家旧译文失效，重新翻译

### Requirement: 译文核对

译文 MUST 经过确定性核对。硬性项为：键与条数一致、无缺译、不含汉字（白名单除外）、四位年份保留；软性项为：其他数字、术语译名、古文固定译文。术语译名写出拼音、完整译名、释义首个短语之一即算合格，不区分大小写、单复数与英式拼写。

有硬性问题时 MUST 在显示前只补译缺项与错项一次，仍不过则整单元再译一次，仍不过则该单元标为失败，并可免费重试。只有软性问题时 MUST 立即采用并显示第一遍译文，再在后台补译一次，补译后软性问题减少且无硬性问题才替换对应条目。

#### Scenario: 漏译一段

- **WHEN** 某单元译文缺少一段
- **THEN** 显示前只补译缺项，不重译整单元

#### Scenario: 只有术语警告

- **WHEN** 某单元第一遍译文只是术语未用规定译名
- **THEN** 立即显示这份译文，后台补译一次，补译更好才替换

#### Scenario: 术语写法宽容

- **WHEN** 译文把「日主」写作「day master」
- **THEN** 术语核对通过，不触发补译

### Requirement: 术语与古文

确定性内容 MUST 走术语表：五行、八卦与六十四卦名、干支（拼音）、十神、六亲、吉凶、事项。卦辞、爻辞、大象传 MUST 用离线译表并标注出处，同一句古文全站 MUST 只有一种译法。英文模式下 evidence 与专家盘（神煞、纳音、黄历、奇门）MUST 隐藏或折叠。

#### Scenario: 同一爻辞

- **WHEN** 结果页的爻辞与某家正文都引用「潜龙勿用」
- **THEN** 两处英文译法一致

### Requirement: 翻译防滥用

服务端 MUST 限制翻译的全局并发，单元连续失败 3 次后 MUST 冷却，并 MUST 有每日单元数熔断，额度由环境变量配置。

#### Scenario: 超出每日额度

- **WHEN** 当日翻译单元数达到上限
- **THEN** 新的翻译请求返回稍后再试，已缓存的译文照常显示

### Requirement: 英文八字结果页图表与中文一致

英文八字结果页 MUST 与中文页展示同一套图表：大运（标出今年所在之运）、流年合议走势图与逐年表、合冲刑害关系图、五行分布条。图表文字 MUST 走术语表：干支写拼音，十神、吉凶、合冲刑害关系名写英文，页面主体不得出现汉字。中文页的图表输出 MUST 保持不变。

#### Scenario: 英文运势结果

- **WHEN** 英文用户打开运势结果或运势示例
- **THEN** 看到流年走势图、合冲刑害图与五行分布条，标签全为英文与拼音，例如「Si–Wu–Wei Fire seasonal union」

### Requirement: 命理新增内容与应期的翻译

翻译单元 MUST 包含命理性格画像各条、三家逐运短评，以及运势三家应期的窗口与条件；服务端单元与前端回填的路径与顺序 MUST 一致。单元文本变化导致旧译文失效时按现有机制重译。

#### Scenario: 英文查看应期

- **WHEN** 英文用户展开运势某家的详断
- **THEN** 应期窗口与条件为英文
