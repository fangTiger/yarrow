# daily-almanac Specification

## Purpose
规定首页免费“今日黄历”的数据内容、接口来源、中英文展示和窄屏形态。本能力为三易首页提供无需模型与付款的每日入口，并可直接引导用户发起今日运势解读。
## Requirements
### Requirement: 首页今日黄历

首页 MUST 免费显示今日黄历：公历与农历日期、日柱、节气、建除与值神、宜忌（各最多 8 项）、冲煞与喜神财神福神方位，数据来自 `/api/now`，不调用模型。卡片 MUST 提供「看看你今天的运势」入口，预填运势与 today。英文版 MUST 通过展示用术语表翻译，查不到的词条不显示，页面不得出现汉字，且不显示彭祖百忌与七十二候。窄屏 MUST 折叠为一行摘要。

#### Scenario: 英文用户打开首页

- **WHEN** 英文模式打开首页
- **THEN** 看到「Today」卡片：日期、日柱拼音、Good for 与 Avoid 的英文事项，没有汉字

### Requirement: 黄历分享图

首页黄历 MUST 提供「分享今日黄历」，在浏览器生成一张分享图，按当前界面语言显示。图上 MUST 有：日期与农历、宜与忌、冲煞、吉神方位，有今日一卦时加上卦名，以及品牌与网址。图片 MUST 在本机生成，不上传服务器。

#### Scenario: 英文分享图

- **WHEN** 英文界面点「Share today's almanac」
- **THEN** 生成英文分享图，宜忌用英文，不出现汉字（品牌印除外）
